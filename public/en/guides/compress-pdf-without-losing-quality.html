THE SMALLER FILE GUIDE

Can you compress a PDF without losing quality?

Sometimes. The honest answer depends on what is inside the PDF, and what you need to preserve.

Updated October 19, 2026 · 4 minute read

Lossless compression and visual quality are different

Lossless optimization reorganizes the PDF or changes its encoding without changing its visible content. It can remove unused objects, combine duplicate resources, and compress document instructions. A PDF that is already optimized may barely shrink.

Image compression can produce a much smaller file while looking very similar at normal reading size. Re-encoding a photo as JPEG or reducing its resolution changes image data, however. “Looks the same” is not a guarantee that every pixel is identical.

Why do scanned PDFs often shrink more?

A scanned PDF can contain a full-page image on every page. A 600 DPI color scan contains far more pixels than a typical screen needs. Optimizing these images can reduce file size substantially. A mostly text-based PDF may already be small because its letters are stored as text instructions rather than photographs of letters.

A photo, a diagram, and a screenshot need different treatment. JPEG often works well for photographs. Images containing small text and fine lines need more caution because visible artifacts can appear around their edges.

How to choose a compression setting

  1. Start with the highest-quality option. Preserve detail first, then see whether the smaller file meets your size limit.
  2. Check representative pages. Include the smallest text, graphs, photos, stamps, and any signatures.
  3. Zoom in. Compare the original and result at your intended reading or print size. A whole-page preview can hide damaged detail.
  4. Try stronger compression only when needed. Keep the original so you can recover details later.

Keep text as text

Converting every page into a compressed picture is simple, but it can sacrifice selectable text, sharp vectors, links, forms, and accessibility. A PDF compressor should preserve the original text and page structure where its optimization mode supports this. If a tool offers a raster or image-only export, read its warning before using it.

What this compressor actually changes

Lossless mode rewrites the PDF structure without intentionally changing its images. It does not promise font subsetting, metadata removal, or resource deduplication. Recommended mode re-encodes eligible, simple 8-bit RGB JPEG images at a high quality setting and preserves their pixel dimensions. Other images are retained.

Stronger mode can also optimize supported raw or Flate-encoded RGB images and reduce eligible images to a longest edge of 2,000 pixels. It uses a lower JPEG quality setting, so inspect small text and fine detail carefully. Complex image resources are skipped. No mode guarantees an identical visual result or a particular reduction.

The tool checks that the output can be parsed and that its page count matches. This is not an automated pixel comparison. Encrypted PDFs, detected signed PDFs, and XFA forms are rejected. Browser memory and device capability limit the files that can be processed.

What about a 100 KB or 1 MB target?

No compressor can guarantee an arbitrary size while preserving all detail. A one-page letter and a 200-page image-heavy report have different limits. If the result is already efficient, further compression may make it larger or require a visible quality trade-off. In that case, keeping the original can be the best outcome.

Documents that need extra care

Rewriting a digitally signed PDF can invalidate its signature, even if the pages look identical. Do not use a compressed derivative as a replacement for a signed original without checking its validity. Also verify forms, accessibility requirements, color-sensitive print work, technical drawings, and documents that must satisfy archival rules. Visual similarity alone does not validate these properties.
