Une question, une erreur à signaler ou une demande sur vos données ?

Mis à jour le 20 octobre 2026

Comment nous contacter ?

Écrivez à report@compresser-pdf.com pour l’assistance, les corrections de contenu ou les demandes de confidentialité. Cette adresse est le point de contact de compresser pdf.

Quelles informations inclure pour un problème technique ?

  • Le navigateur, sa version et le type d’appareil.
  • Le mode de compression, la taille approximative et le nombre de pages.
  • Le message d’erreur et les étapes permettant de reproduire le problème.

N’envoyez pas de PDF confidentiel, de mot de passe ni de lien de connexion. Masquez les informations personnelles sur les captures d’écran.

Comment demander une correction ou exercer vos droits ?

Indiquez la page concernée et la correction proposée. Pour une demande concernant votre compte, écrivez depuis l’adresse associée si possible. Une vérification d’identité peut être nécessaire. La politique de confidentialité décrit les données et leur suppression.
