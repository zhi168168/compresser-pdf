# 页脚徽章管理

管理入口：`https://compresser-pdf.com/admin/badges.html`。使用独立管理密码，不需要注册网站账号。首次生成的管理信息仅保存在被 Git 忽略的本机 `.local/badge-admin-access.txt`，请存入密码管理器；修改密码后以新密码为准。

1. 登录后粘贴对方提供的完整 `<a>…<img …>…</a>` 代码，支持一次添加多个。
2. 点击“解析并添加到草稿”，检查预览和图片状态。可编辑链接、名称、尺寸，调整顺序，隐藏或删除。
3. 点击“保存并发布”。法语、英语全部 12 个页面动态读取同一份配置，通常一分钟内更新，无需部署。已打开的页面每 30 秒及重新切回时同步。

图片源返回 403 等错误时，管理页面会明确提示。可上传获准使用的 PNG / JPG / WebP 图片（单张不超过 100 KB），或填写新的 HTTPS 图片地址。上传图片保存在徽章配置中，不会上传 PDF。图片可来自任意 HTTPS 域名，外链统一在新窗口打开并设置 `noopener noreferrer`。

导出配置会包含当前草稿和上传的图片，可留作备份；导入仅替换草稿，保存后才发布。管理端采用版本检查，避免两个标签页静默覆盖。若发生冲突，先导出草稿，再刷新重新编辑。账号自动备份仍只备份原有账号表，不包含徽章配置；请使用此处导出功能单独备份。

密码可在页面底部修改，至少 12 位；更改后所有管理会话失效。会话保存在 HttpOnly/Secure/SameSite=Strict Cookie 中，有效期 8 小时。数据库只保存密码的 scrypt 哈希和随机会话令牌的 SHA-256 哈希。登录按来源 IP 的不可逆 HMAC 标识限流（每 15 分钟最多 10 次），不记录明文 IP。管理 API 不允许跨来源写入，访客只能读取已启用的徽章，HTML 代码不会作为可执行页面内容保存或运行。

首次初始化：在显式加载生产环境的终端运行 `node --env-file=.env.local scripts/init-badges.mjs`。创建独立的 `site_badges`、`site_badge_admin`、`site_badge_sessions`、`site_badge_attempts` 表，导入原有五个徽章；重复运行不会覆盖线上配置或重设密码。初始化不在构建或请求中自动运行。Preview 环境应继续与生产数据库隔离。

管理页面始终 noindex、不进入 sitemap，响应禁止缓存。公开配置最多缓存 30 秒。配置服务暂时故障时，已加载的页面保留上一次显示内容；新打开的页面使用构建时的原有五个徽章作为回退，因此维护时应以服务恢复后的动态配置为准。
